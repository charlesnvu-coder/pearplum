# Pear Plum — mu.sō-inspired website

A responsive Next.js website combining Pear Plum content with the editorial section flow of musocoffee.com.

## Preview locally

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy safely to Vercel

1. Create a new GitHub repository and upload these project files.
2. Import that repository into Vercel with the Next.js preset.
3. Use a non-production Git branch for changes; Vercel will create a preview deployment.
4. Review the preview URL before merging to the production branch.

## Brand asset note

The source website's exact logo and original photography were not available for download in the build environment. The current wordmark is a typographic interpretation and photos are illustrative remote Unsplash images. Replace these with approved Pear Plum assets before final publication. The plum/pear colors are an interpretation, not sampled brand hex values. All site content and opening date were drawn from pearplum.com (checked October 29, 2026). This is an original implementation, not a pixel-perfect copy of musocoffee.com.
